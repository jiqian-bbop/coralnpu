# Coral NPU Analyzer

该技能专门用于深入分析克隆到本地的 Google Coral NPU 开源项目。通过此技能，Agent 能够快速理解项目的整体架构，并对特定的硬件/软件模块（如标量处理部分）进行深入分析。

## 执行步骤

当用户调用此技能时，请严格按照以下步骤执行分析任务：

### 1. 项目宏观结构分析
- **信息收集**：使用 `Glob`、`LS` 等工具或调用 `search` Agent，扫描并分析项目的顶层目录和关键文件（如 `README.md`, `Makefile`, `CMakeLists.txt` 或构建脚本）。
- **模块划分**：识别出项目的核心组件，例如硬件描述（RTL）、编译器（Compiler）、驱动程序（Driver）、测试用例（Tests）等。
- **结构输出**：向用户输出一份结构清晰的宏观架构报告，说明各个主要目录的职责和项目整体的代码组织方式。

### 2. 标量处理（Scalar Processing）部分定位与分析
- **关键词检索**：使用 `Grep` 和 `SearchCodebase` 工具，在整个代码库中搜索与“标量处理”相关的关键词（如 `scalar`, `scalar_unit`, `scalar_processor`, `ALU` 等）。
- **核心文件定位**：找出实现标量计算和控制逻辑的核心源文件。
- **逻辑分析**：
  - 分析标量处理模块的主要功能和指令集。
  - 分析标量单元与数据流、控制流以及向量/张量计算单元（Vector/Tensor Unit）的交互关系。
- **深度报告**：提取关键代码片段（使用准确的 `startLine:endLine:filepath` 格式引用），并向用户解释标量处理部分的底层实现机制。

## 最佳实践
- **优先使用 Search Agent**：由于 NPU 项目通常代码量庞大且结构复杂，建议在分析时优先指派 `search` 子 Agent 来进行大规模的代码探索和关联分析。
- **保持上下文连贯**：在报告中，确保把微观的代码分析（如标量处理）和宏观的系统架构联系起来，帮助用户理解该模块在整个 NPU 中的作用。
